# QA 证据说明

本目录保存可复核的构建、前台状态、设备截图和交互验证证据。

## 命名

- 构建记录：`YYYY-MM-DD-build.md`
- 交互记录：`YYYY-MM-DD-interaction.md`
- 前台证明：`YYYY-MM-DD-foreground.txt`
- 截图：`screenshots/YYYY-MM-DD-<scene>.png`

## 记录要求

- 写明设备/模拟器、系统版本、构建变体、包名和 Ability。
- 交互记录包含操作前状态、用户动作、操作后状态与结论。
- 截图保留原分辨率,只保留与断言有关的画面。
- 宣传设计图不作为设备运行证明。
- 不保存签名口令、私钥、令牌、个人信息或完整无关日志。

## 当前状态

本目录已包含 phone 与 2in1 的构建、交互、转换产物和截图证据。按日期命名的 Markdown 报告是验收入口；报告引用的截图和转换样本用于复核结论。

原始 UI 层级转储、完整 hilog 和其他临时调试探针不得提交。需要短期保存时统一写入项目根目录 `.hvigor/qa-probes/`，该目录已被 Git 忽略。
