# 首页与关于页参考图精确还原设计

## 目标

以用户在 2026-08-03 提供的两张 phone 截图为最终视觉基准，只重做首页和关于页，不改动任何转换业务、路由与能力声明。

## 首页

- 顶部左对齐 32vp 粗体应用名，下方 15vp 蓝灰副标题。
- 主页插画在标题下居中，phone 高约 190vp，保持完整透明边缘。
- 八个功能入口为两列四行；phone 卡片高 96vp、圆角 14vp，图标位于浅蓝圆形底座内，标题 16vp，说明 12vp。
- 底部导航为白色圆角顶栏，选中项蓝色并显示短下划线；首页内容可滚动但底栏固定。
- 2in1 保持四列并限制内容最大宽度，避免将 phone 尺寸机械放大。

## 关于页

- 不显示独立返回标题栏；作为首页第二个 Tab，顶部留白后居中显示 120vp 应用图标。
- 应用名 28vp 粗体，副标题 17vp 品牌蓝。
- 隐私卡片包含四行，每行左侧使用不同的蓝色线性图标，右侧为 16vp 文案；行间有细分隔线。
- 版本文字居中置于卡片下方；底部导航与首页完全一致。
- 所有可见声明仅使用已经核实的离线、无后端、不上传、不保存用户文件事实。
