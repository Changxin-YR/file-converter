# 文件格式盒应用名称变更设计

## 目标

将用户可见应用名称从“万能格式转换”更改为“文件格式盒”，以获得更贴合本地文件格式转换功能、且更具辨识度的上架名称。

## 范围

- 更新 AppScope 与 entry 的 `app_name` 字符串资源，保证系统桌面、窗口标题和页面名称一致。
- 更新首页、关于页和开发/设计文档中作为产品名称的可见文案与回归契约。
- 不改变 `bundleName`、应用 ID、包名、版本号、签名、路由、图标、离线能力或权限。

## 验收

- 所有 `app_name` 资源一致引用“文件格式盒”。
- 首页、关于页和系统安装后的桌面名称一致。
- 应用图标资源保持现有 1024×1024 RGBA PNG，不重新设计图标。
- 全量契约、类型检查、标准门禁和 HarmonyOS 构建通过；phone 安装后核验首页与关于页名称。
